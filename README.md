# gateflow — 事件驱动门电路回放器

数字板输入最终稳定时，传播延迟不同的两条门路径仍可能在输出上产生短脉冲
（glitch/hazard）。本服务用**事件驱动 + 纯传输延迟（transport delay）**
模型回放这样的电路，输出指定观察点的完整跳变时间线，并标出宽度小于阈值的脉冲。

- 语言：Go（仅标准库）
- 服务：单个 HTTP 服务 `logic`，接口 `POST /simulate`
- 规模：至多 40 个单驱动布尔门（`AND` / `OR` / `XOR` / `NOT`）
- 门延迟：1～8 个整数时刻
- 拓扑：连线必须无环（DAG），否则整份拒绝

## 模拟语义

1. **初始稳态**：主输入取初值，所有门按拓扑序求值一次。无环组合电路一次遍历
   即收敛，因此没有“上电”阶段的虚假跳变。
2. **同刻批量生效**：同一整数时刻 `t`，到期的门输出事件与主输入的外部翻转
   先**一起**生效，之后只重算“本时刻有输入真正变化”的门（每门每拍至多重算
   一次，按拓扑序、依据批量生效后的输入值）。
3. **纯传输延迟**：门在 `t` 算出的值排到 `t+delay` 到期。调度**只追加、从不
   取消**先前已排队的事件——后来的变化不会错误地抹掉前一个待发跳变，所以窄
   脉冲可以穿过多级门（这正是与“惯性延迟”模型的区别）。
4. **忽略同值重复事件**：到期值若与输出端当前值相同，则该事件不产生跳变，
   也不再向扇出传播。
5. 终止条件：外部事件与待发门事件队列都清空。

窄脉冲：观察点时间线上相邻两条跳变之间的电平区间，宽度
`width = t_next - t_cur`，当 `width < glitch_width`（严格小于）时上报，
正毛刺（脉冲期间为高）与负毛刺（脉冲期间为低）都报告。

## 请求 JSON

```json
{
  "inputs": [
    { "id": "A", "init": false, "events": [{ "at": 1 }] }
  ],
  "gates": [
    { "type": "XOR", "id": "z", "delay": 2, "inputs": ["A", "B"] }
  ],
  "observe": ["z"],
  "glitch_width": 3
}
```

- `inputs[]`：主输入。`init` 为 `t=0` 初值；`events[]` 是**翻转**事件
  （旧值取反），时刻为正整数且按同一输入严格升序；时刻及经门延迟后的所有
  输出时刻必须能由有符号整数精确表示，否则整份拒绝。
  不同主输入在同一时刻翻转是合法的；**同一主输入同一时刻翻转两次即“非法同时
  翻转”，整份拒绝**。
- `gates[]`：`NOT` 恰好 1 个输入，其余门至少 2 个输入；同一门的输入线网不得
  重复；`id` 是输出线网名，与主输入共用一个命名空间，且必须**单驱动**
  （门 id 不得与主输入或其它门重名）。
- `observe[]`：要输出时间线的线网，按数组顺序返回。
- `glitch_width`：脉冲宽度阈值，宽度严格小于该值才上报；为 0 时不上报。

## 响应 JSON

```json
{
  "timelines": [
    { "net": "z", "init": false,
      "jumps": [{ "at": 2, "value": true }, { "at": 3, "value": false }] }
  ],
  "pulses": [
    { "net": "z", "from": 2, "to": 3, "width": 1, "value": true }
  ]
}
```

`init` 是**初始稳态**电平；`jumps` 为实际发生的跳变（同值事件已过滤），
时间升序。无跳变时 `jumps` 为空数组。

## 整份拒绝（HTTP 400，`{"error": "..."}`）

重复驱动、组合环（含直接自环）、非法门类型、延迟越界、门输入数非法、
同一扇入重复、引用不存在的线网、同一主输入同时/乱序翻转、翻转时刻非正、
观察点不存在、门数超过 40、门延迟后的输出时刻越过有符号整数上界，以及 JSON
本身非法。

## 运行

本地直接运行：

```sh
go run ./cmd/logic            # 默认监听 :8080，可用 LOGIC_ADDR 覆盖
curl -s localhost:8080/healthz
curl -s -X POST localhost:8080/simulate \
  -H 'Content-Type: application/json' \
  --data @examples/glitch.json
```

Docker Compose（`logic` 服务）：

```sh
docker compose up --build
```

## 测试

引擎与一个**独立实现的逐时刻参考模拟器**（稠密时间桶，单独的拓扑/求值代码）
对拍，覆盖：

- 重汇路径产生的短脉冲（`TestReconvergentGlitch`）；
- 同一时刻多输入变化在门输入上的同刻抵消（`TestSameTickCancellation`、
  `TestEqualDelayReconvergeNoGlitch`）；
- 跨多个门、延迟各异的传播（`TestMultiGatePropagation`）；
- 传输延迟“不取消待发事件”的关键性质（`TestTransportDoesNotCancel`）；
- 同值到期事件被忽略、初始稳态无上电跳变、`init` 不被终态污染；
- 700 个随机无环电路（含 NOT）逐条跳变边与初/终电平对拍；
- 窄脉冲集合用独立算法在随机电路上对拍；
- 全部拒绝路径与 HTTP 端点（200/400/405）。

```sh
go test ./...
go test -race ./...
```
